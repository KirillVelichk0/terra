# Описание проекта
В рамках проекта разворачивается wordpress.
Ресурсы:
- vm под wordpress с cloud-init скриптом
- mysql кластер
- объектное хранилище
- сеть и подсеть
# Политики безопасности
В проекте используются политики безопасности.  
Машине с WordPress разрешен входящий трафик только для портов 8080(http), 4444(https - не используется), 22 - для доступа по ssh. А также, разрешается любой исходящий трафик
Машине с БД разрешен входящий трафик только из приватной подсети и разрешен любой исходящий
# Переменные
В демонстративных целях я оставил terraforms.tfvars с используемым публичным ключом и идентификатором папки.  
В случае запуска нужно подставить актуальный переменные.  
Все необходимые данные для аутентификации yc находятся в env, перед запуском их необходимо настроить у себя локально
